# 📝 DecodeLabs Internship – Python To-Do List

A simple and practical **To-Do List application built using Python** as part of my DecodeLabs Internship. This project focuses on applying Python programming concepts to create a useful task-management application.

## 🚀 Project Overview

The **Python To-Do List** allows users to manage their daily tasks efficiently. Users can add new tasks, view existing tasks, update their task status, and maintain their task data using a JSON file.

This project helped me strengthen my understanding of **Python programming, file handling, data structures, functions, and basic application development**.

## ✨ Features

* ➕ Add new tasks
* 📋 View existing tasks
* ✅ Mark tasks as completed
* 🗑️ Manage tasks efficiently
* 💾 Store task information using JSON
* 🔄 Load saved tasks when the application starts
* 🖥️ Simple and beginner-friendly interface
* 📂 Persistent task storage

## 🛠️ Technologies Used

* **JSON**
* Python Lists and Dictionaries


## 💡 How It Works

1. The application starts by loading previously saved tasks from `tasks.json`.
2. The user can select an operation from the available options.
3. New tasks can be added to the task list.
4. Tasks can be viewed and managed.
5. Updated task information is stored back in the JSON file.
6. The saved data remains available when the application is run again.
